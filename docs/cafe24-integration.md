# Cafe24 Integration Checklist

1. 기존 PC/모바일 스킨 HTML, CSS, JS, 공통 헤더·푸터·상품 상세를 백업한다.
2. 현재 운영몰의 메뉴/카테고리 번호, 상품번호, 약관·사업자 정보, 로그인/검색/장바구니 경로를 확인한다.
3. `assets/css/style.css` 디자인 토큰·그리드·반응형을 카페24 스킨 구조에 맞춰 이전한다.
4. `assets/js/main.js` 의 임시 제품 배열을 실제 카페24 상품 목록 모듈로 **교체**한다. 가격·재고·옵션을 정적 코드에서 관리하지 않는다.
5. 회원/검색/장바구니/주문/결제는 카페24 기본 모듈을 유지한다.
6. PC/모바일 상품 상세, 옵션 선택, 장바구니 담기, 쿠폰/할인, 회원 비회원 주문, 결제, 개인정보처리방침 등 실사용 테스트를 진행한다.
7. 운영몰 반영은 테스트 스킨 검수 및 백업 뒤 수행한다.

현재 GitHub Pages는 **디자인 미리보기**만 제공합니다. 카페24 데이터 연동이 자동으로 되는 것은 아닙니다.

## 2026-10-18 고객 피드백 반영
- GitHub 시안 헤더 메뉴: SHOP(상품 미리보기), 실사용 후기(공식몰 리뷰 게시판), 멤버쉽(공식몰 회원 로그인). 정적 미리보기의 멤버쉽은 카페24 회원 서비스로 이동합니다.
- 신규 회원 혜택 띠배너는 웜 샴페인 베이지(#D9C7AD), 헤더는 연한 베이지(#F5EFE5)로 시안 통일. 최종 컬러는 승인된 메인 배너 색상과 대조 후 조정.
- 글자 가독성: 메뉴 600, 기본 텍스트 450~500, 제품명 600. 모바일 16px 메뉴.
- 제품 이미지 품질: 현재 정적 시안의 제품 사진은 플레이스홀더입니다. 실제 원본(1000×1000 이상 권장)을 카페24 상품 대표이미지에 등록하고, 카페24 썸네일 리사이징/이미지 URL/저해상도 파일 확대 여부를 점검해야 합니다. CSS만으로 저해상도 이미지를 복구할 수 없습니다.
- 운영 카페24에 별도 자동 배포되지 않습니다. 기존 헤더/메인 파일 및 카페24 모듈을 보존하며 테스트 스킨에서 적용하십시오.
