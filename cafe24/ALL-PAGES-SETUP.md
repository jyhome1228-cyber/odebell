# 카페24 전체 페이지 헤더 적용 및 스크롤 고정

스크린샷의 Gallery 페이지에 이전 O'de Bell 헤더가 보인 것은 **해당 페이지가 신규 레이아웃이 아닌 다른 스킨 레이아웃을 사용 중일 가능성**을 보여줍니다. 라이브 카페24 관리자 설정은 확인하지 못했으므로 원인을 확정할 수는 없습니다.

## 반드시 확인
1. 카페24 스마트디자인 → PC 디자인 → 공통 레이아웃에서 **메인** 및 **상품/게시판 등 서브페이지** 레이아웃 파일을 각각 찾습니다. 스킨별 이름/위치가 다를 수 있습니다.
2. 각 레이아웃에 동일한 `ode-header` 마크업을 포함하고, 기존 `<!--@contents-->`, 결제·해외배송 관련 모듈은 그대로 남깁니다.
3. **기존 헤더 import와 새 헤더 마크업을 동시에 유지하면 헤더가 중복**되므로, 실제로 적용하는 레이아웃마다 하나만 선택합니다. 기존 header.html의 로그인 상태·카트 수량·언어 모듈은 확인 후 이식해야 합니다.
4. CSS/JS 파일을 카페24에 업로드하고, 메인·서브 공통 레이아웃 양쪽에 다음을 추가합니다. GitHub 코드를 올렸다고 카페24에 자동 배포되지는 않습니다.

```html
<!--@css(/weskin_import/css/odebell-shared-header.css)-->
<!--@js(/weskin_import/js/odebell-sticky-header.js)-->
```

5. sticky-header.js는 .ode-header가 있을 때만 실행됩니다. 기존 .header에는 적용되지 않습니다.
6. 게시판(Gallery/Notice/Review), 상품 목록, 상품 상세, 로그인·회원가입, 장바구니 페이지에서 동일한 헤더가 출력되는지 확인합니다.
7. 스크롤 시 상단 검정 혜택 배너가 위로 사라지고 **흰색 메뉴 헤더만 상단에 고정**되는지 확인합니다.
8. 디자인이 적용됐더라도 실제 회원/결제/카트 기능은 **복제 스킨에서** 확인 후 운영 스킨에 적용하십시오.

## 확인되지 않은 부분
- 실제 스킨의 각 서브페이지가 참조하는 레이아웃 경로
- 카페24 관리자 배포 여부
- 헤더 원본 소스의 동적 모듈 구성
